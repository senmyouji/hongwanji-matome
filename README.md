# hongwanji-matome

「浄土真宗本願寺派 全国の法話・行事・寺報まとめ」（https://senmyouji.or.jp/matome/ ）と、
「浄土真宗本願寺派のお寺を探す」（https://senmyouji.or.jp/shinshu-hp/ ）の表示用データとスクリプトです。

専明寺が運営する非公式の新着案内です。本願寺派（本山）とは関係ありません。
著作権は各寺院にあり、本文は各寺院のホームページでお読みください。
掲載停止・訂正のお申し出は https://senmyouji.or.jp/contact/ へお寄せください（3日以内に対応します）。

- `data/items.json` … 新着の一覧（題・寺院名・日付・元記事へのリンク・短い紹介文）
- `data/temples.json` … ホームページのある寺院の一覧
- `js/matome.js`・`js/temple-list.js` … 表示用スクリプト
